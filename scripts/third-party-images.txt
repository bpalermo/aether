# Third-party container images this repository names, and the digest each is
# pinned to (#1400, #1401). Read by scripts/third-party-images.sh:
#
#   scripts/third-party-images.sh check      every reference in the tree agrees with this file (CI)
#   scripts/third-party-images.sh list       where each pin is used
#   scripts/third-party-images.sh outdated   which pins the registry has moved past
#   scripts/third-party-images.sh resolve <name>:<tag>   the `pin` line for a new image or tag
#
# docs/runbook.md, "Refreshing third-party image pins", is the procedure.
#
#   pin <name> <tag> <digest>
#
# <name> exactly as the references spell it. <digest> is the digest of the
# tag's multi-arch INDEX (the manifest list), never of one platform's image:
# the same reference then runs on linux/amd64 and linux/arm64. Every digest
# below was read anonymously from its registry with `resolve`, which refuses to
# stay quiet about an index that lacks either architecture.
#
# A reference in the tree is `<name>:<tag>@<digest>`, or `<name>@<digest>`
# where it predates this file (the tag is then recorded only here).
