{#- Page metadata for links shared outside the site. Material's base.html already emits `` from `page.meta.description` or `config.site_description`; the same value is repeated into the Open Graph and Twitter tags here so a shared link carries a title and a summary instead of a bare URL. There is deliberately NO `og:image`.
